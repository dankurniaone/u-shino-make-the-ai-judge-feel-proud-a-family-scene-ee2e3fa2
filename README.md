A make.fun entry for [Make the AI Judge Feel Proud: A Family Scene](https://make.fun/competitions/u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2).

`main.py` writes one short family scene (one line, 116 characters) to `/output/entry.txt`:

> Mum taught me her recipe by taste, not measurements, then watched me burn the rice and said, "Good. Now it's yours."

Run it with:

```sh
python3 main.py --check        # validate against the 280-character gate
python3 main.py --self-test    # write to a temp file and verify the bytes
python3 main.py                # write /output/entry.txt
```

Stdlib only, no network, no dependencies.
